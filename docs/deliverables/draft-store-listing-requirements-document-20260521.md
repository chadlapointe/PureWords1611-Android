# Google Play Store Listing Requirements Document  
**Project:** PureWords1611-Android  
**Purpose:** Publish a high-quality Android app and restore Google Play developer standing with at least one successfully published app.

## 1) Core Store Listing Fields

Google Play requires the following store listing assets and metadata:

### Required listing content
- **App name**
- **Short description**
- **Full description**
- **Category**
- **App icon**
- **Screenshots**
- **Featured graphic**
- **Contact details**
- **Pricing status**
- **Privacy policy URL** if the app collects personal information or is designed for children

### Optional / conditional assets
- **Promotional video**: optional, but supported and commonly recommended
- **Website / phone contact**: optional
- **Ads disclosure**: required if the app contains ads

## 2) Requirements Summary

### App name
- **Maximum length:** 30 characters
- Should accurately describe the app’s function
- Avoid:
  - version numbers
  - price claims
  - ranking claims
  - emoji or repetitive symbols
- Best practice: include meaningful keywords naturally, without stuffing

### Short description
- **Maximum length:** 80 characters
- Should summarize the app’s main value proposition clearly and concisely
- Focus on one compelling benefit
- Avoid:
  - pricing claims like “free”
  - promotional ranking claims like “best” or “#1”

### Full description
- **Maximum length:** 4,000 characters
- Should explain:
  - core purpose
  - key features
  - benefits
  - what makes the app unique
- Must be truthful, clear, and not misleading
- Avoid keyword stuffing
- First few sentences matter most, since many users only read the opening text

### Category
- Select the category that best fits the app
- For a word-based or vocabulary app, likely candidates include:
  - **Word** if treated as a game
  - **Education**
  - **Books & Reference**
  - **Productivity**
  - **Tools**
- Choose based on actual app purpose and experience

### App icon
- **512 x 512 px**
- **32-bit PNG with transparency**
- Must comply with Google Play icon design requirements
- Should be visually clear at small sizes

### Screenshots
- **2 to 8 screenshots** per supported device type
- Supported device types may include:
  - phone
  - tablet
  - Android Wear
  - Android TV
- Format:
  - JPEG or 24-bit PNG
  - no alpha transparency
- Size:
  - minimum 320 px on any side
  - maximum 3840 px on any side
- Best practice:
  - show key features
  - keep screenshots clean and representative
  - usually avoid device navigation bars, but include status bar

### Featured graphic
- **1024 x 500 px**
- JPG or 24-bit PNG, no alpha
- Displayed prominently on the listing
- If a promo video is used, the featured graphic may have a play button overlay in Google Play surfaces, but the actual graphic should not include the play icon

### Promotional video
- YouTube URL
- Typically used to promote the app
- Common best practice:
  - 30 to 60 seconds
  - keep it short, focused, and engaging
- Can be unlisted on YouTube if preferred before launch

### Contact details
- **Email address required**
- Website address optional
- Phone number optional
- These appear in the store listing

### Pricing
- Must choose:
  - **Free**, or
  - **Paid**
- If paid, ensure pricing decisions align with your release strategy and review Google’s pricing documentation

### Privacy policy URL
- Required if:
  - the app collects personal information, or
  - the app is designed for children
- Must be an active webpage URL
- PDF links are not acceptable

## 3) Best-Practice Guidance from Google

Google’s store listing guidance emphasizes:

- Make the **title accurate and descriptive**
- Keep descriptions:
  - succinct
  - honest
  - clear
  - user-focused
- Highlight:
  - app benefits
  - unique features
  - interesting facts
- Provide attributed sources for any testimonials or quotes
- Don’t include:
  - fake or unattributed testimonials
  - misleading claims
  - offers or discounts in the description
  - store-performance claims

## 4) Recommendations for PureWords1611-Android

Since this app is intended to showcase **word-based, educational content**, the store listing should strongly reflect that positioning.

### Suggested category direction
If the app is primarily a word game or vocabulary activity:
- **Game > Word**

If the app is more educational or language-learning focused:
- **Education**

If the app functions more like a utility or study aid:
- **Books & Reference** or **Tools**

### Suggested title strategy
Use a title that:
- includes the brand/app name
- communicates the use case
- stays under 30 characters

Example patterns:
- `PureWords 1611: Word Game`
- `PureWords 1611: Vocabulary`
- `PureWords 1611: Bible Words`

### Suggested short description strategy
Keep it to one clear sentence:
- emphasize vocabulary
- emphasize word puzzles
- emphasize learning or engagement
- avoid marketing fluff

Example:
- `Bible-inspired word puzzles to build vocabulary and focus`

### Suggested full description structure
Use a simple structure:
1. What the app is
2. What the user can do
3. Key features
4. Why it stands out
5. Call to action

Possible feature themes:
- word challenges
- vocabulary growth
- educational gameplay
- scripture or language-based content
- simple clean Android experience
