# Screenshot Mockup Guide for Play Store

**Purpose**: This guide provides detailed specifications and mockup descriptions for creating screenshots for the Google Play Store listing.

**Last Updated**: December 25, 2024

---

## 📱 Screenshot Requirements Summary

- **Minimum Required**: 2 phone screenshots
- **Recommended**: 4-6 phone screenshots
- **Optional**: Tablet screenshots (7" and 10")
- **Format**: JPEG or 24-bit PNG (no alpha channel)
- **Recommended Resolution**: 1080 x 1920 px (portrait) or 1920 x 1080 px (landscape)
- **Aspect Ratio**: 16:9 or 9:16
- **Orientation**: All screenshots should use the same orientation (portrait recommended)

## 📐 Technical Specifications

### File Specifications
- **Format**: JPEG (preferred for photos/complex graphics) or PNG (for flat designs)
- **Bit depth**: 24-bit (no alpha channel)
- **Color profile**: sRGB
- **Maximum file size**: ~5-8 MB per screenshot (Play Console limit)

### Recommended Resolutions

**Portrait Phone Screenshots** (Recommended):
- 1080 x 1920 px (Full HD)
- 1440 x 2560 px (Quad HD)
- 1440 x 2880 px (18:9 ratio)

**Landscape Phone Screenshots**:
- 1920 x 1080 px (Full HD)
- 2560 x 1440 px (Quad HD)

**7-inch Tablet Screenshots**:
- 1200 x 1920 px (portrait)
- 1920 x 1200 px (landscape)

**10-inch Tablet Screenshots**:
- 1600 x 2560 px (portrait)
- 2560 x 1600 px (landscape)

### Device Frame Guidelines
- **Do NOT** include device frames in official screenshots (Google may add them)
- Exception: If creating promotional images outside Play Store, frames are OK
- Keep screenshots as raw screen content only

## 🛠️ Tools for Creating Screenshots

### Option 1: Real App Screenshots (Ideal)
If app is built:
1. **Android Studio Emulator**:
   - Run app in emulator
   - Click camera icon to capture
   - Screenshots saved to desktop
   
2. **Physical Device**:
   - Run app on phone
   - Use device screenshot (Power + Volume Down)
   - Transfer to computer via USB or cloud

3. **ADB Command**:
   ```bash
   adb shell screencap -p /sdcard/screenshot.png
   adb pull /sdcard/screenshot.png
   ```

### Option 2: Design Tool Mockups (Before App is Built)
1. **Figma** (Recommended, Free):
   - Use phone frame templates
   - Design screens based on mockup specifications
   - Export as PNG/JPEG at correct resolution
   
2. **Adobe XD** (Free):
   - Create artboards at exact pixel dimensions
   - Design app screens
   - Export for Play Store
   
3. **Sketch** (Mac only, Paid):
   - Professional design tool
   - Many app UI templates available
   
4. **Canva** (Free/Freemium):
   - Use custom dimensions
   - Simpler tool for basic mockups
   - Good for text-heavy apps like Bible verse app

### Option 3: Screenshot Mockup Services
1. **Screenshots.pro**: Generate mockups from designs
2. **Mockuphone**: Free device mockup generator
3. **Smartmockups**: Professional mockup creator

### Before Creating
- [ ] Review all mockup specifications in this document
- [ ] Choose design tool (Figma recommended if app not built)
- [ ] Gather fonts and color palette
- [ ] Select verse content for each screenshot
- [ ] Decide on portrait or landscape orientation

### For Each Screenshot
- [ ] Create at correct resolution (1080 x 1920 px recommended)
- [ ] Include realistic status bar (time, battery, signal)
- [ ] Use consistent fonts and colors across all screenshots
- [ ] Include verse text, reference, and relevant UI elements

## 💡 Pro Tips

### Design Tips
1. **Keep It Real**: Show actual verse content, not "Lorem ipsum"
2. **Less Is More**: Don't overcrowd screenshots
3. **Consistency**: Use same design system across all screenshots
4. **Readability**: Ensure text is large enough to read on small displays
5. **Highlight Features**: Use subtle visual cues to draw attention to key features

### Technical Tips
1. **Use Templates**: Start with device frame templates for consistency
2. **Export 2x**: Create mockups at 2x resolution then scale down for sharper images
3. **Clean Status Bar**: Show good signal, full battery, reasonable time (10:10 AM is commonly used in Android screenshots)
4. **Test on Device**: View screenshots on actual phone to check readability
5. **Name Files Clearly**: Use descriptive names like `phone_01_daily_verse.png`

### Content Tips
1. **Popular Verses**: Use well-known, encouraging verses
2. **Avoid Sensitive**: Don't use controversial or difficult verses in marketing
3. **Show Variety**: Use verses from different parts of the Bible
4. **Proper Citations**: Always include book, chapter, verse, and "(KJV)"
5. **Check Accuracy**: Verify verse text is accurate to 1611 KJV
